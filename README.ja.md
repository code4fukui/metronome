# metronome

Web Audio APIの `AudioWorklet` を使用して構築された、シンプルでWebベースのメトロノームです。正確で低遅延なオーディオスケジューリングを実現します。

## デモ

https://code4fukui.github.io/audioworklet-test/

## 特徴

- **高精度なタイミング**: `AudioWorklet` APIを使用してオーディオ処理を別スレッドで実行し、メインスレッドの負荷によるクリックノイズや音の途切れを防ぎます。
- **調整可能なコントロール**: UIのスライダーを使用して、テンポ（BPM）やマスターボリュームを簡単に変更できます。
- **複数のサンプル**: 複数の `.wav` ファイルを読み込み、異なる音（例: 基本のクリック音とダウンビート用のベル音）を再生できます。
- **デバイス選択**: 好みのオーディオ出力デバイスを選択できます。

## 仕組み

このプロジェクトは、ブラウザ上で高精度なオーディオスケジューリングを行うための堅牢な手法を示しています。

1. メインスレッドがUIを処理し、`.wav` オーディオサンプルを読み込みます。
2. `AudioWorkletNode`（`SamplesNode`）が作成され、カスタムの `SamplesProcessor` が専用の高優先度オーディオスレッドで実行されます。
3. オーディオサンプルと再生パラメータ（スライダーによるテンポ変更など）は、メインスレッドから `port.postMessage` を通じてワークレットに送信されます。
4. オーディオエンジンによって `SamplesProcessor` の `process()` メソッドが呼び出され、次のオーディオバッファが埋められます。リアルタイムで音波を計算することで、UIの更新や他のメインスレッドのタスクに影響されることなく、メトロノームのタイミングを一定に保ちます。

## 使い方

1. [デモページ](https://code4fukui.github.io/audioworklet-test/)を開きます。
2. （オプション）ドロップダウンメニューから希望のオーディオ出力デバイスを選択します。
3. **VOL**と**TEMPO**のスライダーを調整して好みに設定します。デフォルトのテンポは120 BPMです。
4. `START` ボタンをクリックして再生を開始します。
5. `STOP` ボタンをクリックして再生を終了します。

## 動作環境

- `AudioWorklet` APIをサポートするモダンブラウザ（例: Chrome 77+、Edge 79+、Firefox 76+）。
